
Redesign the existing *Overoll Club loyalty programme* to create a more minimal, elegant, modern and premium user experience.

Use the existing screens, features, user flows and overall design logic as the foundation. *This is a visual refinement and UX improvement, not a complete redesign of the product's functionality.*

The new interface should feel consistent with the visual identity of the Overoll Croissanterie website.

## 1. Visual Direction

Create a clean, minimal and sophisticated interface with an editorial design approach.

- *Primary background:* Pure white (#FFFFFF).
- *Secondary background:* Soft, warm beige, used selectively.
- *Accent colours:* Overoll pink and purple, used sparingly for buttons, icons, active states, labels and subtle decorative details.
- *Typography:* Black or near-black for all primary text. Avoid the grey typography of the previous design.
- Use generous whitespace, clear alignment and consistent spacing.
- Incorporate thin borders, delicate lines and restrained graphic elements.
- Maintain a refined, lightweight visual hierarchy.
- Avoid heavy shadows, excessive rounded cards, large solid-colour backgrounds and unnecessary decorative components.

The interface should feel airy, polished and premium rather than playful, crowded or overly colourful.

## 2. Brand Identity and Design Language

Take inspiration from Overoll's existing website design language:

- Elegant editorial layouts with balanced negative space.
- Thin pink outlines and understated visual accents.
- Clear black typography combined with delicate pink headings.
- Product photography as a strong visual element where appropriate.
- Minimal outlined buttons and refined navigation elements.
- Subtle geometric details and careful use of asymmetry.
- Clean white surfaces with occasional beige sections.

Do not reproduce the website layout literally. Translate its visual identity into a functional mobile-first loyalty application.

Preserve the existing Overoll logo and established brand identity.

## 3. Header and Bottom Navigation

*Header*

Every main application screen must include a consistent, fixed top header featuring the Overoll logo.

Keep the header minimal, with a white background, appropriate spacing and subtle separation from the screen content.

*Bottom Navigation*

Every main application screen must include a persistent bottom navigation bar with the existing navigation destinations:

- Card
- Rewards
- Stores
- Profile

Use simple, consistent outline icons. Highlight the active destination with a subtle pink or purple accent.

*Important exception:* Do not display the header or bottom navigation on splash, onboarding, login or registration screens.

## 4. Splash Screens and Onboarding

Expand the current welcome and registration experience into a more detailed, intuitive multi-screen flow.

Create separate screens for:

1. *Brand Splash Screen:* Minimal introduction featuring the Overoll logo.
2. *Welcome Screen:* Introduce Overoll Club and its main value proposition.
3. *How It Works:* Explain how customers collect points through purchases.
4. *Rewards Introduction:* Explain how points can be redeemed for products.
5. *Registration:* Provide a clean, easy-to-complete sign-up experience.
6. *Verification:* Include a dedicated verification step where required.
7. *Registration Success:* Confirm successful membership and guide the user to their digital loyalty card.

Use progress indicators, clear calls to action and concise Greek copy.

Keep these screens visually connected through consistent typography, spacing and subtle brand elements.

All onboarding and registration screens must remain free of the standard application header and bottom navigation.

## 5. Main Application Screens

Apply the updated design system consistently across the existing screens.

*Digital Loyalty Card*

- Emphasise the member's QR code and points balance.
- Use white as the dominant background.
- Present membership status and progress in a clean, structured layout.
- Use pink and purple selectively to highlight important information.
- Maintain easy access to Apple Wallet and Google Wallet.

*Rewards*

- Replace visually heavy cards with cleaner reward rows or lightweight components.
- Keep point requirements, reward descriptions and redemption actions clearly visible.
- Make available and unavailable rewards easy to distinguish.
- Preserve the existing loyalty tiers and redemption logic.

*Redemption*

- Keep the QR code or redemption code highly visible.
- Display the reward, expiration countdown and cancellation action clearly.
- Prioritise simplicity and usability during checkout.

*Stores*

- Use a clean, easily scannable list of Overoll locations.
- Apply subtle dividers, black typography and restrained accent colours.
- Maintain a consistent navigation experience.

*Profile*

- Present membership details, loyalty status and account settings in a minimal, organised structure.
- Use clear section headings and simple interaction patterns.

## 6. Components and Interaction Details

Create a consistent component system covering:

- Primary and secondary buttons.
- Input fields and registration forms.
- Navigation icons and active states.
- Reward rows and redemption components.
- Progress indicators and loyalty tiers.
- QR code containers.
- Informational messages and success states.

Prefer lightweight outlines, consistent spacing, limited colour fills and subtle visual feedback.

Ensure good readability, accessible contrast and comfortable touch targets.

## 7. Content and Functional Requirements

- Keep *all user-facing interface copy in Greek*.
- Preserve existing loyalty rules, point calculations, membership tiers, rewards and redemption conditions.
- Do not introduce new business rules without explicit approval.
- Maintain consistency across web, iOS and Android experiences.
- Design for mobile-first use, with reusable components and a coherent design system.
- Keep the existing screen functionality intact while improving clarity and usability.

## 8. Expected Deliverables

Produce an updated, fully editable Figma design that includes:

- The revised visual design system.
- Expanded splash, onboarding and registration screens.
- Redesigned Card, Rewards, Redemption, Stores and Profile screens.
- Consistent fixed header and bottom navigation across authenticated application screens.
- Reusable UI components and interaction states.

## Final Design Principle

*The new Overoll Club should feel like a natural extension of the Overoll Croissanterie brand: minimal, refined, clean and premium.*

Use white space as the primary visual tool, beige for warmth, black for typography, and pink and purple only where they add meaning.

Preserve the existing product logic while significantly improving visual consistency, simplicity and the overall user experience.
